   metadata components, run dependency/hash checks, the frozen B4 coverage

## Reproduce the read-only preflight

```bash
python tools/audit_release_candidate.py \
  --previous release-v0.10.1 \
  --graph outputs/unknotdb-embedding-shortcut-13n984-v2.sqlite \
  --identification outputs/unknotdb-graph-identification-snappy-v6.sqlite \
  --runtime runtime/target/release/unknotdb-runtime \
  --output outputs/release-preparation-20260921-v2.json
```

The output must not already exist. The tool reads inputs in SQLite read-only
mode, validates graph replay, hashes inputs before and after, and never
repins, promotes or uploads anything. Its `assembly_ready=false` is deliberate:
this is a candidate preflight, not a complete release gate.
